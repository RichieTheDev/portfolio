# Richie Momodu | Portfolio

Personal portfolio for Richie Momodu, DevOps Engineer.

Live: https://richiemomodu.vercel.app

## Stack

- Next.js 15 (App Router, static export of the home page)
- React 19, TypeScript
- Tailwind CSS 3

## Development

```bash
npm install
npm run dev
```

Content (experience, skills, projects, links) lives in `app/data.ts`.
